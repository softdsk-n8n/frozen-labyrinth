# Frozen Labyrinth — интерактивная карта (Lineage 2: Interlude)

Локальное веб-приложение: карта локации Frozen Labyrinth с мобами, NPC, квестом 648 и советами по фарму. Стек: HTML5 + CSS3 + Vanilla JS + Leaflet.js (CDN).

## Запуск

```bash
node tools/serve.cjs        # → http://localhost:3999
```

Или любой статический сервер из этой папки (например, `npx serve`).

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | DOM-структура, подключение Leaflet/data/app |
| `styles.css` | L2-стилистика: тёмные панели, золото, снегопад |
| `data.js` | База: 20 мобов + 6 NPC + рейд-босс + 4 портала, квест 648, гайд, i18n RU/EN |
| `app.js` | Инициализация Leaflet (CRS.Simple), маркеры, фильтры, попапы, квест-подсветка |
| `labyrinth_map.png` | Карта локации |
| `icons/` | Игровые иконки скиллов/предметов (l2api.dev) |
| `img/mobs/` | Рендеры мобов с l2db.ru (`<npcId>.png`, реальные модели Interlude) + портреты NPC |
| `tools/gen-data.cjs` | Генератор data.js из кеша API + спавнов датапака |
| `tools/convert-spawns.cjs` | Конвертация игровых координат спавнов в координаты карты |
| `tools/png-light.cjs` | Анализ светлых (проходимых) зон карты |
| `tools/serve.cjs` | Мини static-сервер без зависимостей |

## Возможности

- **RU/EN** — переключение без перезагрузки (сохраняется в localStorage)
- **Точки спавна** — 571 реальная точка из датапаков (красные = агро, зелёные = пассивные), заполняют коридоры по всей локации, включая западный и северный лучи; клик — карточка, наведение — тултип
- **Список мобов** — выпадающее меню в панели: клик по мобу → подсветка его спавн-зоны (пульсация) + полёт камеры, повторный клик — снять
- **Фильтры**: Все / NPC / Агрессивные / Пассивные
- **Карточки-мобы** — компактный игровой стиль: квадратный портрет, HP-полоска как в клиенте (зелёная→красная, у босса — ледяная), уровень 60+ подсвечен оранжевым, слабости/резисты чипами с иконками, дроп/спойл в две колонки, золотые уголки рамки
- **Квест 648** «Мечта ледяного торговца»: шаги, квест-предметы, кнопка подсветки всех 20 мобов из списка охоты
- **Гайд по фарму**: коридоры, агро-предупреждения, спойл-цели, мост к Сирре
- **Оформление**: шрифт Cinzel для заголовков, заголовок «Frozen Labyrinth» поверх карты, ледяная виньетка, роза ветров, трёхслойный снегопад, снежинка-favicon
- **Dev-хук**: `window.__fl` в консоли — доступ к карте (`__fl.select(id)`, `__fl.openCard(id)`); клик по карте → координаты `[y, x]` в консоль

## Источники данных

- Статы, скиллы, дроп/спойл: [explorer.l2api.dev/interlude](https://explorer.l2api.dev/interlude) (официальные цифры хроник)
- **Спавны (расстановка мобов)**: датапак L2J Interlude — `spawnlist.sql` из [Hl4p3x/L2JServer_C6_Interlude](https://github.com/Hl4p3x/L2JServer_C6_Interlude) + скрытый эндпоинт l2api `/npcs/{id}/spawns`, итого 649 сырых спавнов; игровая система координат конвертирована в координаты карты откалиброванным линейным трансформом (`tools/convert-spawns.cjs`, flipY + scale 0.80), снап к белым зонам — 571 точка (~39% покрытия проходимых коридоров)
- Иллюстрации мобов: [l2db.ru](https://l2db.ru/npc/view/22085/interlude) — рендеры реальных моделей Interlude (`user_images/<id>_gf.png`)
- Топология/описание коридоров: [l2vika.ru — Frozen Labyrinth](https://l2vika.ru/lokacii/frozen-labyrinth.html)
- RU-переводы имён — community-стиль, легко правятся в `data.js`

Нюансы: Lost Iron Golem (22091) и Ursus Cub (22095) в этом датапаке не спавнятся — стоят рядом со старшими версиями; Lost Bandersnatch и Baby Panthera в датапаке по 1 спавну; порталы-выходы — оценка (в датапаке нет).

## Правка координат

Координаты мобов берутся из датапака (`tools/spawns-map.json`). Клик по карте печатает `[y, x]` в консоль браузера (F12) — для тонкой подгонки правь `spawns-map.json` и перегенерируй: `node tools/gen-data.cjs`.
